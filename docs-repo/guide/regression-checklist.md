# 关键交互回归清单

本文用于执行 Phase H2 的手工回归，建议在每轮 UI/交互改动后至少跑一遍。

## 环境准备

1. 启动 Playground：`pnpm --filter block-editor-playground dev`
2. 访问场景：`/scenes/default?theme=dark&lang=zh-CN`
3. 重点切换验证：`theme=light|dark|auto`、`lang=zh-CN|en-US`

## H2.1 评论

1. 选中文本后点击工具栏“添加评论”，评论侧栏应自动展开。
2. 引用预览应显示在输入框上方，点击可跳转到原文位置。
3. 输入评论后点击提交，未输入正文前不应直接保存。
4. 点击行内评论标注应展开评论侧栏并定位线程。

## H2.2 链接

1. 插入链接弹窗文案应随语言切换。
2. 插入后 hover 链接应出现预览；点击内部 hash 链接应跳转块位置。
3. 在暗黑模式下预览和弹层颜色应为主题色，不出现白底突兀弹层。

## H2.3 表格工具栏

1. 光标进入表格时浮出工具栏，离开表格后自动收起。
2. 列/行/表操作菜单文案应走 i18n。
3. 插入行列、删除、合并/拆分应正常执行。

## H2.4 Block Handle 菜单

1. Hover 块左侧出现 handle，点击弹出菜单。
2. 菜单项文案应随语言切换。
3. 上下移动、复制块、删除块、转类型操作可用。
4. 暗黑模式下菜单背景/边框/hover 颜色应与主题一致。

## H2.5 Selection Tooltip

1. 选中文本后弹出工具条，按钮状态与实际格式一致。
2. Dropdown、ColorPicker 在暗黑模式不应出现白色弹层。
3. Esc/点击外部可关闭弹层，不应残留悬浮菜单。

## 记录模板

```md
- 分支/提交：
- 场景：
- 结果：通过 / 失败
- 失败项：
- 修复提交：
```
