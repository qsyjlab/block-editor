## 1. 评分模型

1. 单项评分：`2=符合`、`1=可接受`、`0=不符合`。
2. 权重：`P0*3`、`P1*2`、`P2*1`。
3. 发布门槛：
4. P0 不允许出现 `0` 分项。
5. `pnpm release:gate` 必须全绿。

## 4. 发布门禁执行链路

`pnpm release:gate`

1. `pnpm test:unit`
2. `pnpm test:e2e`
3. `pnpm --dir docs docs:build`

任何一步失败都视为“未通过发布门禁”。

CI 同步门禁：`.github/workflows/behavior-gate.yml` 在 `push/pull_request` 执行同一条 `pnpm release:gate` 链路。
