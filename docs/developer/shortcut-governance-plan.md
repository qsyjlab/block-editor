# 快捷键统一治理与演示页计划

最后更新：2026-03-30  
状态：执行中（S1~S4 部分完成）

## 1. 目标定义

建立一套可扩展、可审计、可国际化的快捷键治理体系，并提供可回放的演示页面，确保：

- 快捷键定义唯一来源（Single Source of Truth）。
- 不同模块（Toolbar / SelectionToolbar / BlockHandle / Table / Comment / FindReplace）快捷键行为一致。
- 快捷键冲突可检测、可告警、可文档化。
- 用户和开发者均可通过 docs 快速理解“支持什么键、在哪些场景生效、冲突怎么处理”。

## 2. 范围边界

### 2.1 本期范围（In Scope）

- 新建统一快捷键注册中心与类型定义。
- 接入现有快捷键（查找替换、文本样式、块操作、导航类）。
- 增加快捷键冲突检测与日志输出。
- 新增 playground “快捷键演示页面”（含场景切换与实时提示）。
- 补齐使用文档与开发文档（调用链路、扩展方式、回归清单）。

### 2.2 非本期范围（Out of Scope）

- 用户自定义快捷键持久化（配置文件/后端存储）。
- 多人协作下的个性化热键同步。
- IME 深度适配与跨应用级全局热键抢占。

## 3. 统一设计方案

### 3.1 架构分层

1. `ShortcutRegistry`：统一注册、注销、查询、冲突检测。
2. `ShortcutResolver`：按上下文（编辑区/弹层/输入框）解析是否生效。
3. `ShortcutDispatcher`：执行命令并回写 telemetry/日志。
4. `ShortcutHints`：UI 展示层（tooltip、菜单右侧、帮助页）。

### 3.2 数据结构（建议）

- `id`: 全局唯一，例如 `find.open`、`text.bold`。
- `scope`: `global | editor | selection | table | comment | modal`
- `combo`: 平台映射（mac / windows）
- `when`: 生效条件（只读、焦点区域、选区状态、节点类型）
- `action`: 触发命令（core command 或 event）
- `priority`: 冲突仲裁优先级
- `i18nKey`: 文案键（tooltip/帮助页复用）

### 3.3 冲突处理规则

- 同 scope + 同 combo + when 重叠视为冲突。
- 默认按 `priority` 决策，低优先级项输出告警并记录到开发日志。
- docs 维护“冲突白名单”与“禁止重复表”。

## 4. 分阶段执行计划

### Phase S1：基线梳理（1 天）

- 盘点现有散落快捷键定义（源码路径 + 触发条件 + 文案）。
- 输出迁移映射表：旧入口 -> 新注册中心。
- 交付物：
  - 快捷键盘点表（docs）
  - 冲突初筛清单（P0/P1）

### Phase S2：核心框架落地（1~2 天）

- 实现 `ShortcutRegistry/Resolver/Dispatcher`。
- 接入 `FindReplace`、基础文本命令（Bold/Italic/Underline）、撤销重做。
- 增加注册期冲突检测（开发环境告警）。
- 交付物：
  - 核心模块代码
  - 单测（注册/覆盖/冲突/上下文匹配）

### Phase S3：全模块接入（1~2 天）

- 接入 SelectionToolbar、BlockMultiSelect、Table 工具栏、评论相关命令。
- 对输入框/弹层场景补“焦点优先”规则，避免输入时抢焦点。
- 交付物：
  - 全量快捷键接入
  - 回归用例清单更新

### Phase S4：演示页与文档（1 天）

- 在 playground 新增“快捷键演示页”：
  - 显示可用快捷键列表（按模块分组）
  - 实时显示最近触发动作
  - 冲突项高亮提示
  - 平台切换（Mac / Win）
- 文档补齐：
  - 使用文档：快捷键总览与操作示例
  - 开发文档：注册 API、冲突规则、调用链路

### Phase S5：验收与门禁（0.5~1 天）

- 补齐 e2e（关键快捷键 + 焦点边界 + 弹层优先级）。
- 产出验收报告（通过率、冲突剩余项、遗留风险）。

## 5. 验收标准

- 功能性：核心快捷键可触发且行为与按钮一致。
- 一致性：tooltip/菜单文案与实际快捷键一致（i18n 控制）。
- 稳定性：输入框场景不抢焦点，滚动/弹层下不误触。
- 可维护性：新增快捷键无需散点改动，走统一注册流程。
- 文档性：使用文档与开发文档均可独立指导使用/扩展。

## 6. 快捷键演示页要求（Playground）

- 路由：`/playground/shortcuts`（建议）
- 页面模块：
  - 左侧：快捷键分类与过滤（编辑/选区/表格/评论/全局）
  - 中间：可操作编辑区（支持回放）
  - 右侧：触发日志 + 当前上下文状态
- 必须支持：
  - 按键触发即时反馈
  - 与工具栏按钮行为对照
  - 平台显示切换（⌘/Ctrl 映射）

## 7. 文档更新要求（每次迭代必做）

- `docs/todo/current.md`：更新任务状态与执行日志。
- `docs/usage/regression-checklist.md`：补充回归项。
- `docs/developer/call-chains.md`：更新调用链路。
- 本文档：补阶段状态、风险、下一步动作。

## 8. 风险与缓解

- 风险：历史快捷键分散，迁移期易漏项。  
  缓解：先跑全量盘点，再分模块切换，不做“边写边猜”。

- 风险：输入焦点冲突导致体验回归。  
  缓解：统一焦点策略（输入控件优先）+ e2e 覆盖。

- 风险：不同平台键位展示不一致。  
  缓解：统一映射层，UI 只消费映射结果。
