配套基准文档：`/usage/behavior-benchmark`。

## 评论链路

1. 选中文本 -> 点击“添加评论” -> 评论区展开并预填引用。
2. 选中文本后，顶部工具栏“添加评论”与选区工具栏“添加评论”应保持一致行为（都预填引用且不自动保存）。
3. 未输入正文时不应直接保存评论。
4. 点击行内评论标注 -> 评论区展开并定位线程。
5. 在 `default / inline-toolbar / custom-layout-a / custom-layout-b / modular-layout / behavior-benchmark / drag-showcase / table-showcase / regression` 场景，评论区都应可见且可展开（不允许出现触发后无面板）。

## 链接链路

1. 插入链接弹窗文案随语言变化。
2. hover 内链显示预览；点击 hash 链接跳转到块。

## 表格与块菜单

1. 表格工具栏显示/隐藏正常。
2. 表格左上角专属 handle 可见，点击后整表出现高亮选中态。
3. 表格 handle 在表格边缘应稳定可点，不应出现“鼠标刚移过去就消失”。
4. 表格区域优先表格 handle，块级 handle 不应抢占造成误判。
5. block handle 菜单动作可执行且暗黑样式一致。
6. `layoutSchema.modules.blockHandle.enabled=false` 时，块手柄与菜单必须完全隐藏。
7. 长按块手柄拖拽需满足触发阈值（按住约 `180ms` 且位移达到约 `6px`），短按不应误触拖拽。
8. 拖拽结束后不应残留高亮线、源块半透明态或手柄拖拽态。

## 行内工具栏

1. 选区工具栏图标默认可见，hover/active 状态清晰。
2. 下拉、tooltip 不应出现白底/裁切/错位。

## 代码块高亮

1. 代码块语言切换后应立即出现对应语法高亮（首次切换允许轻微加载延迟）。
2. 语言下拉单击一个选项即可切换，不应需要点击两次。
3. 首次切到某语言后再次切换同语言，不应重复卡顿（应命中已加载缓存）。
4. 暗黑/浅色模式下 token 颜色都应可读，不出现“全白/全灰”。
5. 连续切换 3 次以上语言，最终语言正确且菜单不残留加载态。

## 图片预览

1. 图片点击一次进入选择态并显示对齐工具条。
2. 图片选中后不应再出现一套“文本选区工具栏”，页面只保留图片工具条。
3. 打开预览入口为：再次单击图片、双击图片、或图片工具条“预览”按钮。
4. 预览是黑色半透明遮罩，右上角关闭按钮可用。
5. 预览底部工具栏应可用：上一张、下一张、比例、旋转、放大、缩小、下载。
6. 预览支持 backdrop 点击、Esc 关闭。
7. 预览中支持拖拽图片位置（平移）以及缩放联动（含滚轮缩放）。
8. 预览底部工具栏层级应高于图片与编辑区，不可被覆盖。
9. 图片中部交互时优先图片自身操作（预览/对齐/resize），左侧边缘才出现块级 handle。
10. caption 编辑态下块级 handle 不应抢占焦点或 hover（`/scenes/drag-showcase` 已开启 caption 供专项回归）。

## P0 复现脚本（本轮基线）

1. 脚本 A（图片点击异常）：
2. 打开 `/scenes/regression?theme=dark&lang=zh-CN&collab=0`。
3. 定位图片区域，首次单击图片应只进入选中态并显示图片工具栏。
4. 再次单击图片应打开预览，关闭后仍保持当前块上下文，不应跳到上一个段落块。
5. 脚本 B（预览异常）：
6. 在预览弹层中滚轮缩放、拖拽平移、Esc/遮罩关闭分别验证。
7. 要求工具栏层级始终高于图片，拖拽跟手，无滚动穿透。
8. 脚本 C（非图片块拖拽失败）：
9. 打开 `/scenes/drag-showcase?theme=dark&lang=zh-CN&collab=0`。
10. 分别拖拽段落、标题、引用、代码块、列表、Callout、表格、图片到目标段落前后，均应出现落点高亮并成功重排。

## 块类型拖拽矩阵（8类）

| 块类型  | 场景锚点                 | 预期                        |
| ------- | ------------------------ | --------------------------- |
| 段落    | `#drag-source-paragraph` | 可拖拽、可重排、无重复插入  |
| 标题    | `#drag-source-heading`   | 可拖拽、标题语义保持        |
| 引用    | `#drag-source-quote`     | 可拖拽、块结构保持          |
| 代码块  | `language-ts` 代码块     | 可拖拽、代码内容不丢失      |
| 列表    | `#drag-source-list`      | 可拖拽、列表层级保持        |
| Callout | `#drag-source-callout`   | 可拖拽、类型样式保持        |
| 表格    | `#drag-source-table`     | 可拖拽、单元格内容保持      |
| 图片    | `#drag-source-image`     | 可拖拽、无空段落/无重复图片 |

补充验证：

1. 对任意块执行拖拽后，编辑区不应出现浏览器默认 drop 导致的额外文本或重复节点。
2. 连续两次拖拽不同块，第二次落点高亮应正常，第一次状态应全部清理。

## 框选多块与组拖拽

1. 从编辑区左侧 gutter 按住鼠标拖出框选框，可批量选中多个顶层块。
2. 框选后会显示多选覆盖层与多选操作栏。
3. 在任一已选块左侧出现 handle 后拖拽，需整组块一起移动，且保持原组内顺序。

## 查找与替换

1. `Cmd/Ctrl+F` 打开查找面板，输入关键词后应显示命中计数（如 `2/7`）。
2. `Enter` / `Shift+Enter` 应切换下一条/上一条命中，并自动定位到文中对应位置。
3. `Cmd/Ctrl+H` 打开替换行，支持“替换当前”与“全部替换”。
4. 全部替换后，文档内容、命中计数与当前定位应同步更新。
5. `Esc` 可关闭查找面板，不应影响后续正常输入。
6. 查找命中应有高亮，当前命中与普通命中需有视觉区分。

## 快捷键统一管理（阶段回归）

1. `Mod+F` / `Mod+H` 在编辑区与查找输入框内触发行为一致。
2. 查找面板打开时按 `Esc` 仅关闭面板，不应误清空正文选区。
3. 存在块多选时按 `Esc` 应清空多选；无多选时不应误触发其他行为。
4. 新增快捷键若与既有快捷键冲突，开发环境应出现冲突告警日志。
