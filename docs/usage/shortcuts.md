# 快捷键总览

最后更新：2026-03-31

本页提供当前内置快捷键清单。演示入口：`/scenes/shortcuts?theme=dark&lang=zh-CN&collab=0`。

## 1. 编辑区

| 功能 | Mac | Windows |
| --- | --- | --- |
| 撤销 | `⌘Z` | `Ctrl+Z` |
| 重做 | `⇧⌘Z` | `Ctrl+Shift+Z` |
| 重做（兼容） | `⌘Y` | `Ctrl+Y` |
| 加粗 | `⌘B` | `Ctrl+B` |
| 斜体 | `⌘I` | `Ctrl+I` |
| 下划线 | `⌘U` | `Ctrl+U` |
| 删除线 | `⇧⌘X` | `Ctrl+Shift+X` |
| 行内代码 | `⌘E` | `Ctrl+E` |
| 代码块 | `⌥⌘C` | `Alt+Ctrl+C` |
| 清除格式 | `⌥⌘0` | `Alt+Ctrl+0` |
| 缩进 | `⌘]` | `Ctrl+]` |
| 减少缩进 | `⌘[` | `Ctrl+[` |
| 无序列表 | `⇧⌘8` | `Ctrl+Shift+8` |
| 有序列表 | `⇧⌘7` | `Ctrl+Shift+7` |
| 任务列表 | `⇧⌘9` | `Ctrl+Shift+9` |
| 引用块 | `⇧⌘B` | `Ctrl+Shift+B` |

## 2. 查找与评论

| 功能 | Mac | Windows |
| --- | --- | --- |
| 打开查找 | `⌘F` | `Ctrl+F` |
| 打开替换 | `⌘H` | `Ctrl+H` |
| 关闭查找面板 | `Esc` | `Esc` |
| 打开评论面板 | `⌥⌘M` | `Alt+Ctrl+M` |

## 3. 多选块

| 功能 | Mac | Windows |
| --- | --- | --- |
| 清空多选 | `Esc` | `Esc` |
| 删除已选块 | `⌫ / ⌦` | `Backspace / Delete` |
| 上移已选块 | `⌥↑` | `Alt+↑` |
| 下移已选块 | `⌥↓` | `Alt+↓` |

## 4. 表格

| 功能 | Mac | Windows |
| --- | --- | --- |
| 上方插入行 | `⌥⌘↑` | `Alt+Ctrl+↑` |
| 下方插入行 | `⌥⌘↓` | `Alt+Ctrl+↓` |
| 左侧插入列 | `⌥⌘←` | `Alt+Ctrl+←` |
| 右侧插入列 | `⌥⌘→` | `Alt+Ctrl+→` |

## 5. 说明

- 所有快捷键由统一注册中心管理，按钮与快捷键默认保持行为一致。
- 输入框内默认不抢占键盘，只有显式允许的项（如查找/替换）会生效。
- 如果你在扩展中新增快捷键，需同步更新 `/developer/shortcut-inventory` 与本页。
